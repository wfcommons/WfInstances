# Snakemake Execution Instances

This directory contains workflow execution instances generated from
[Snakemake](https://snakemake.readthedocs.io/en/stable/) executions. The instances
hosted in this directory use
[WfFormat](https://github.com/wfcommons/wfformat) for describing workflow
executions.

### Workflow Applications

The workflow execution instances recorded in this directory are from
the following applications:

- [RASflow](https://github.com/zhxiaokang/RASflow)
- [Varlociraptor](https://github.com/snakemake-workflows/dna-seq-varlociraptor)
- [rna-seq-star-deseq2](https://github.com/snakemake-workflows/rna-seq-star-deseq2)

### Workflow Simulator

The execution instances provided in this directory are compatible with any
[simulation framework](https://wfcommons.org/simulation) that implements
[WfFormat](https://github.com/wfcommons/wfformat).
